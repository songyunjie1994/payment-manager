# 支付管理系统

上传支付截图（支付宝 / 微信 / 银行App），自动 OCR 识别金额、日期、收款方、支付方式，生成可视化支付报表，支持导出 Excel。

## 功能

- 🖼️ 图片上传（多张、拖拽），本地 OCR 识别（Tesseract.js，中文+英文）
- 🧠 自动解析：金额、日期时间、收款/付款方、支付方式、订单号、收/支方向
- ✏️ 识别结果可点击单元格直接修改
- 📊 报表：总笔数 / 总金额 / 本月统计，月度趋势图、支付方式分布、收款方 Top8
- 🔍 按月份 / 支付方式 / 关键词筛选
- 📥 一键导出 Excel（明细 + 月度汇总 + 对方汇总 三个 Sheet）
- 💾 数据保存在浏览器本地（localStorage），不上传服务器，隐私安全

## 使用

直接访问 GitHub Pages 地址即可，或下载 `index.html` 双击用浏览器打开。

> 建议使用 Chrome / Edge 浏览器。首次识别需加载 OCR 语言包（约几 MB，稍等片刻）。

## 技术栈

纯静态单页应用：Tesseract.js（OCR）+ Chart.js（图表）+ SheetJS（Excel 导出），无需后端。
